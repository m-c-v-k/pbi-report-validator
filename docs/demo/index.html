pbi-report-validator

Compare two versions of a Power BI report and see what changed.

This demo compares two synthetic sample reports from the repository (tests/fixtures/sales_v1 and sales_v2). The second version removes a visual filter, changes a slicer selection, renames a measure, moves and retypes a visual, adds a page and edits a measure expression. The reports below are generated by CI on every release.

  • HTML report
    Summary, page wireframes and a drill-down per visual
  • Markdown summary
    The text posted as a pull request comment
  • JSON output
    Every finding with old and new values, for CI

Try it on your own reports (saved as PBIP in the PBIR format):

uv tool install git+https://github.com/m-c-v-k/pbi-report-validator
pbi-validate diff ./old ./new --html report.html
